# KnowledgeHub AI

An AI-powered multi-tenant enterprise knowledge platform that allows organizations to securely upload internal documents and enables employees to ask natural-language questions with permission-aware RAG, grounded answers, and source citations.

## Phase 1 Status
This repository is currently established at Phase 1: Project Setup.

## Tech Stack
- Frontend: Next.js + React + TypeScript + Tailwind CSS
- Backend: Python + FastAPI + SQLAlchemy(async) + asyncpg
- Database: PostgreSQL + pgvector (via Supabase)
- Identity & Storage: Supabase Auth & Storage

*Please see `phase_0_architecture.md` for full architectural details.*
